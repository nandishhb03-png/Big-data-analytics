# Exercise 5 – Hadoop MapReduce: Sales Data Analysis

## Aim
To perform sales data analysis using the Hadoop MapReduce framework by processing a sales dataset and calculating the total sales for each city.

## Objective
- Understand the working of Hadoop MapReduce.
- Write custom Mapper and Reducer programs in Python.
- Process a CSV dataset stored in HDFS.
- Generate city-wise sales totals using MapReduce.

## Files Included
- generate_sales.py
- sales_data.csv
- mapper_city_sales.py
- reducer_city_sales.py

## Software Requirements
- Ubuntu (WSL)
- Hadoop 3.5.0
- Python 3
- Java (OpenJDK)

## Procedure
1. Generate the sales dataset.
2. Upload the dataset to HDFS.
3. Execute the Hadoop Streaming MapReduce job.
4. Process the input using the Mapper.
5. Aggregate the results using the Reducer.
6. Display the output.

## Expected Output
City-wise total sales generated using the Hadoop MapReduce framework.

## Conclusion
The experiment successfully demonstrated the use of Hadoop MapReduce for analyzing sales data using Mapper and Reducer programs.
