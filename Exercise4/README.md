# Exercise 4 - Hadoop MapReduce Word Count on Multiple Files

## Objective
To create multiple text files, upload them to HDFS, execute the Hadoop MapReduce Word Count program on all files, and identify the top 3 most frequent words.

## Files Included
- file1.txt
- file2.txt
- file3.txt
- output.txt

## Procedure
1. Create an HDFS directory.
2. Create three input text files.
3. Upload the files to HDFS.
4. Verify the uploaded files.
5. Execute the Hadoop MapReduce Word Count program.
6. View the generated output.
7. Find the top 3 most frequent words.

## Result
The Hadoop MapReduce Word Count program was executed successfully on multiple input files. The output displayed the frequency of each word, and the top three most frequent words were identified successfully.
