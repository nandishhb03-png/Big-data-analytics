# Exercise 6 - Weather Data Analysis using Hadoop MapReduce

## Aim
To analyze weather data using Hadoop MapReduce and identify the coldest day from the given dataset.

## Objective
- Learn Hadoop Streaming.
- Implement Mapper and Reducer in Python.
- Process weather data stored in HDFS.
- Find the day with the minimum temperature.

## Files
- weather_large.txt
- mapper_max_temp.py
- reducer_min_temp.py
- reducer_max_temp.py

## Software Used
- Ubuntu (WSL)
- Hadoop 3.5.0
- Python 3
- Java

## Procedure
1. Create the weather dataset.
2. Upload the dataset into HDFS.
3. Execute the Hadoop Streaming job.
4. Run the Mapper and Reducer.
5. Display the output stored in HDFS.

## Output

Coldest Day: 2024-01-03 with 10.0°C

## Conclusion
Successfully analyzed weather data using Hadoop MapReduce and identified the coldest day.
