# Exercise 7 - Sales Analysis using Hadoop MapReduce

## Aim
To analyze sales data using Hadoop MapReduce and identify the top 5 products based on total sales.

## Objective
- Learn Hadoop Streaming.
- Implement Mapper and Reducer using Python.
- Process sales data stored in HDFS.
- Find the top-selling products.

## Files
- sales_products.txt
- sales_products_large.txt
- mapper_top_products.py
- reducer_top_products.py

## Software Used
- Ubuntu (WSL)
- Hadoop 3.5.0
- Python 3
- Java

## Procedure
1. Create the sales dataset.
2. Upload the dataset into HDFS.
3. Execute the Hadoop Streaming job.
4. Process the data using Mapper and Reducer.
5. Display the final output.

## Output

TOP 5 PRODUCTS BY SALES

1. Laptop : ₹6,750,000.00
2. Monitor : ₹2,500,000.00
3. Keyboard : ₹350,000.00
4. Mouse : ₹225,000.00

## Conclusion

Successfully analyzed sales data using Hadoop MapReduce and identified the top-selling products.
