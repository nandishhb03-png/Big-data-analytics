# Exercise 10 - Hadoop and Cassandra Integration

## Objective

Integrate Hadoop and Cassandra to implement a Lambda Architecture supporting real-time analytics and batch analytics for a music streaming platform.

## Components

* Hadoop HDFS
* Hadoop Streaming MapReduce
* Apache Cassandra
* Docker
* Python

## Features

* Real-time analytics using Cassandra
* Batch analytics using Hadoop MapReduce
* Hybrid analytics combining both systems

* jobs/
